# Contributing

Describe the donor model and the exact Enderwire 300 hardware variant. Include measurements and photographs sufficient to reproduce a mechanical change. Record the source and revision of imported CAD/STLs and retain their license notices.

For configuration changes, state the board revision, driver type, motor assignment, sensor identity, and actual wiring. Remove passwords, network credentials and unrelated machine identifiers. A successful configuration parse is not proof of safe motion or correct thermal control; report the physical checks completed.

Keep unverified values clearly marked. Do not replace pending measurements with dimensions from the smaller Pro/V2 project. Update relevant guide sections and the build record together. Add original photos to `docs/images/build/` using the photo checklist.
