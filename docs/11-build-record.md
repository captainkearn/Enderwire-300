## Release checklist

- [ ] Selected BOM includes verified quantities and dimensions.
- [ ] Every adapted part has its source, revision and changes recorded.
- [ ] Both CoreXZ belt paths and all bearing/spacer stacks are illustrated.
- [ ] Final board revisions and complete connection worksheet are recorded.
- [ ] Hotend, heater and temperature sensor are positively identified.
- [ ] A reviewed, tested Klipper configuration is added without credentials.
- [ ] Homing, travel, heaters, fans, Z reference and first layers pass testing.
- [ ] Final photographs replace misleading reference views and retain accurate captions.
- [ ] Licenses and notices are retained for every imported design/image set.
