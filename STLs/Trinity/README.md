## Choosing parts

These are source files, not a verified Enderwire 300 print set. Some are alternative mounts, display options, or source-specific accessories. The `Stealthburner Assembly` folder is retained for completeness; Enderwire 300 uses Dragon Burner, so do not print or install every Stealthburner part by default.

Follow [the parts selection guide](../../docs/02-parts.md) before printing. Source filenames containing `x2` or `x4` retain the author's naming and are not independently validated assembly quantities.

The [inventory](../../bom/trinity-file-inventory.csv) records each file's original relative path, byte size, and SHA-256. Append that relative path to this directory to locate the matching mesh.
